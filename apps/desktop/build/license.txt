1. WHAT NOVAREC IS
================================================================================

NovaRec is a desktop application for recording your screen, camera, microphone
and system audio, for running meetings, and for exporting the result as a video
file. It runs on your machine. It requires no account.

5. PRIVACY - THE SHORT VERSION
================================================================================

NovaRec is a local application. Your recordings, settings and any credentials
you enter stay on your machine. Ife Solutions Ltd operates no server that
receives them.

STORED ON YOUR MACHINE ONLY:
  - recordings and exported files, in the folder you choose;
  - capture setup, preferences and export history;
  - any LiveKit or Google credentials you enter, encrypted at rest by the
    operating system's own key store (DPAPI on Windows).

NETWORK USE. NovaRec is usable entirely offline. It contacts the network only
to: (a) check GitHub Releases for updates, which reveals your IP address and
version to GitHub; (b) carry meeting audio/video to the LiveKit server you
configured, if you start a meeting; (c) hand a Google Meet link to your browser,
if you open one; (d) accept a connection from your own phone ON YOUR LOCAL
NETWORK ONLY, if you use the "Connect a phone" camera feature - that video
travels directly between your phone and this computer, never through any
server on the internet; and (e) send anonymous usage telemetry, if and only if
you switch it on.

PHONE CAMERA PAIRING. If you pair a phone as a camera, NovaRec briefly listens
for a connection on your local network. It runs only while pairing, shuts down
when you disconnect, when the app quits, or after five minutes idle, and
requires the one-time token from the QR code on every request. It serves one
page and a fixed set of connection-setup endpoints, and cannot read or serve
any file on your computer. Full detail is in docs/PRIVACY.md.

TELEMETRY IS OFF BY DEFAULT. It stays off until you enable it in
Settings > Privacy. When enabled it sends anonymous usage events only. NovaRec
never sends file names, folder paths, window or screen titles, recording
content, transcripts, or anything derived from them.

The full privacy policy is in docs/PRIVACY.md in the project repository.
